# iny-measure

**낸 글 한 편이 검색과 AI 답변에 실제로 걸리나 날마다 재는 Claude Code 스킬입니다.**

에셋엔진 워크플로우의 **08단계**입니다. `v1.0`

---

## ★ 사이트가 아니라 글 한 편을 잽니다

07 도 재고 08 도 잽니다. **재는 대상이 다릅니다.**

| | 07 TECH | **08 MEASURE** |
|---|---|---|
| 대상 | 사이트 전체 (사이트맵을 돕니다) | **글 한 편** |
| 언제 | 짓고 나서 · 가끔 | **낸 뒤 날마다** |
| 내는 것 | 감사표 · 글쓰기규칙 · 등급표 | 점검표 · 색인 여부 · 인용 A/B/C |

**06 이 지은 질문을 그대로 씁니다.** 글 쓸 때 쓴 질문으로 성과를 잽니다.

---

## 세 가지를 잽니다

```
글 주소 하나  +  06 이 지은 그 글의 질문
        ↓
① 기준 항목에 대고 ○·✕            → 점검표.md
        ↓
② 빙 목록에 올랐나                 → 안 올랐으면 여기서 멈춥니다
        ↓
③ 질문마다 AI 네 곳에 물어 A/B/C   → 인용.md (날마다 한 줄씩)
```

| 판정 | 뜻 |
|---|---|
| **A** | **출처로 걸림.** 내 도메인이 AI 답의 출처 목록에 있습니다 |
| **B** | 이름만 언급. 출처엔 없는데 답 글자 안에 내 이름이 있습니다 |
| **C** | 안 나옴 |
| 아직 | **색인 전.** C 가 아닙니다 |
| 못잼 | 입력칸을 못 찾았거나 답이 안 나왔습니다. 이유를 적습니다 |

---

## ★ 못 믿는 0 을 적지 않습니다

**색인 전에 재면 전부 「안 나옴」이 나옵니다. 그건 실패가 아니라 아직입니다.**

그래서 08 은 **빙에 올랐나부터 봅니다.** 안 올랐으면 인용을 아예 안 잽니다.

| 상황 | 적는 것 |
|---|---|
| 빙에 색인 안 됨 | **「아직」.** C 가 아닙니다 |
| 엔진이 제 집을 출처로 냄 | **뺍니다.** 퍼플렉시티 답에 퍼플렉시티가 26번 나오는 건 아무 뜻이 없습니다 |
| 어제 파일이 남아 있음 | **잰 때를 보고 오늘 것만 셉니다** |

---

## ★ 이름이 아니라 도메인으로 셉니다

**한국어에서 짧은 이름은 다른 말 안에 다 걸립니다.**

「이니」로 세면 「많이니」 「때문이니」 「것이니」에 전부 걸립니다.
실제로 네이버에서 두 건이 그렇게 **거짓으로 B** 가 된 적이 있습니다.

> **못 잡는 쪽이 잘못 잡는 쪽보다 낫습니다.**
> 잘못 잡으면 안 되고 있는 걸 되고 있다고 읽습니다.

그래서 **도메인처럼 다른 말과 안 겹치는 것만** 「나」 목록에 넣습니다.
여섯 글자 미만은 스크립트가 아예 거부합니다.

---

## 로그인을 안 합니다

로그인하면 그 계정이 그동안 뭘 물었는지가 답에 섞입니다.
**남들이 보는 답과 달라져서 잰 값을 못 믿습니다.**

| 엔진 | 잴 수 있는 것 |
|---|---|
| Perplexity | 출처를 순서대로 줍니다. **몇 번째인지까지** 잽니다 |
| 구글 AI 개요 | 〃 |
| 네이버 AI 브리핑 | 〃 (블로그 위주) |
| ChatGPT | **버튼을 눌러 「웹 검색」을 켜야** 웹을 뒤집니다. 안 켜면 기억으로만 답합니다 |

**ChatGPT 는 출처를 링크가 아니라 버튼으로 줍니다.** 이름 앞에 파비콘 글자가 한 자 붙어서
그걸 안 떼면 도메인과 못 맞춥니다. 그 처리가 스크립트에 들어 있습니다.

## 알아둘 것

### 짐작해서 ○ 를 안 적습니다

받아본 것만 적습니다. 못 잰 칸은 **「나중에」가 아니라 「무엇을 하면 잴 수 있는지」**로 적습니다.

### 검색 콘솔 숫자는 여기서 안 봅니다

콘솔을 **붙인 날부터만** 숫자가 쌓입니다. 붙이기 전 기간은 영영 안 나옵니다.
그래서 08 을 기다리지 마시고 **지금 붙여두시는 게 값이 큽니다.**

### 브라우저가 하나 필요합니다

AI 답변 화면은 프로그램으로 물으면 안 나옵니다. **사람처럼 눌러 봐야** 나옵니다.
자동화 브라우저는 대개 봇으로 막힙니다. 실제로 같은 화면을 하나는 0개, `ego lite` 는 9개를 잡았습니다.
